# 疾病来源靶点查询与药材候选排序

日期：2026-10-23。P2b 已在7877源码聊天接入 `disease_gene_profile` 和 `rank_herbs_for_gene_set`。输入明确疾病来源后，在本地计算集合交集及排名；结果属于来源关联研究，尚无独立疾病特异性、机制或治疗有效性验证。

## 启动和提问

需要上一阶段的疾病索引、现有药材资料，以及已安装 `requirements-research-chat.txt` 的Python环境。不要直接使用缺少依赖的Conda `(base)`；本机已验证环境可用 `/tmp/tcm-ci-mail-env/bin/python` 替换下方 `python`。该路径位于临时目录，长期使用请按[环境准备](PROJECT_DEMO.md#启动与复现)创建项目虚拟环境。

启动命令：

```bash
python -m scripts.preview_local_tasks --port 7877 \
  --diseases var/disease_catalog_v1/build/diseases.sqlite3
```

打开 http://127.0.0.1:7877/ ，直接输入：

```text
查询疾病 Dermatosis Papulosa Nigra 的靶点资料
按疾病 Dermatosis Papulosa Nigra 的靶点找候选药材，前5个
疾病 Dermatosis Papulosa Nigra 的候选药材，按共同靶点数排序，前5个
回看分析结果
```

该英文名称沿用来源数据库原名。中文疾病别名尚未核验，不自动翻译或替换；同名多来源先选择。保留 `--with-intent-model` 可启用已经授权的当前问句意图兜底，仅发送问句和静态工具定义；上述示例都通过本地规则，无需模型。2026-10-23本次启动排障后，7877按用户命令加载疾病索引并关闭外部模型；需要模型意图兜底时，重启命令显式加 `--with-intent-model`。

复杂含逗号名称可用明确指令，完整名称不拆开：

```text
/analysis disease Dermatosis Papulosa Nigra --page 2
/analysis disease-rank Dermatosis Papulosa Nigra --top-k 5 --metric common_count
```

未知名称、超过20项、缺库或版本变化不会生成候选。没有可用靶点或没有背景交集时返回空结果，不解释为该疾病不存在关联。不知道完整英文名时，可用“查找疾病 diabetes”或“浏览疾病目录”，见[名称查找](DISEASE_NAME_SEARCH.md)。原名不完整的分析请求会列候选供选择并保留原参数。新增示例不能保证所有改述被识别；旧字段规则可能先匹配“来源”等词，遇到范围不对可使用上述明确指令。

## 页面和计算

疾病资料按每页20条展示来源靶点与基因符号，原行/JSON位置折叠；可以翻页并进入候选排序。排序默认前10项、最多20项，可在Jaccard与共同靶点数间切换，保留返回数量。

| 列 | 含义 |
| --- | --- |
| Jaccard | 共同标识数 / 疾病和药材完整标识并集数 |
| 共同靶点 | 两份来源明确共有的UniProt数量 |
| 疾病覆盖 | 共同标识数 / 疾病完整集合大小 |
| 背景内覆盖 | 共同标识数 / 疾病集合中药材背景覆盖的标识数 |

背景外标识保留在完整集合，不在计算Jaccard时删除。源内重复行先去重计算，原行继续保留。同分按另一指标及来源ID稳定排序，未覆盖药材不当作已确认负例。与同一非空靶点集合相对应的不同疾病来源会得到相同排名，页面显示这种不可区分性。

“查看”可展开共同及双方独有标识；“双方原始记录”显示前3个共同标识，每侧每个标识最多3条原行，并附疾病/药材文件SHA与路径。这个有界证据样本不是全部共同靶点的原行导出；可通过按钮进一步查看完整分页来源列表。

真实示例来源含283个去重标识，其中279个在当前药材背景、4个在背景外；另有7条疾病来源具有相同集合。来源物种未记录，抓取状态按原样保留，不能将候选排名当成用药、疗效或新靶点预测。

## 调用链和工程约束

`/chat → 本地规则/一次模型意图 → LangGraph assistant → analysis_tools固定注册表 → disease_analysis → 只读疾病索引和药材集合 → 严格输出Schema → 表格`。

模型只能选择注册工具和填写严格参数，不执行任意SQL/Python，不接收检索资料或历史。两个新增工具的描述/参数/能力名称沿用同一注册表，仍不是全项目工具迁移、MCP或自主循环规划。

疾病查询复用上一阶段版本化索引；候选排序复用 `target_similarity` 的去重集合、完整药材来源映射验证、只读事务和确定性排序。绑定疾病目录指纹，以及药材数据版本、来源指纹和背景集合哈希；背景不匹配或查询期间目录变化拒绝结果。疾病读入仍以内容哈希定位来源，页面不独立重读所有原文件；原始文件一致性通过既有索引构建和专项原JSON核对保证，手动改文件后应重建索引。

会话只保存工具、疾病来源ID、页码/排序/数量参数和组合修订指纹，不保存整批靶点或原行。刷新与“回看分析结果”重新读取当前目录；数据变化拒绝旧焦点。测试覆盖存储对象重开，未在本轮单独进行真实服务重启后的旧会话验收。

新增文件 `tcm/disease_analysis.py`、`tests/test_disease_analysis.py`；调整分析注册表、意图Schema、规则、集合计算、页面与预览启动参数。没有修改原JSON或数据库Schema，没有新增缓存、后台队列或大规模并发验证。
