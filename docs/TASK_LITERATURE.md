# 任务来源文献线索与对象核验契约

优先级更新：文献扩展现已冻结，保留现有可选ID线索，不继续文献抓取或审核平台开发。核心任务对照和后续方向见[工作流选择](CORE_WORKFLOW_COMPARISON.md)。下文为已完成能力与历史计划。

2026-10-21为ETCM本地任务新增“读取来源文献ID（本地）”，并复用现有文献元数据和原文引用校验模块，建立后续文献适配的纯函数契约。本轮未联网获取文献、未调用模型；真实ETCM只在本地读取，文献对象核验测试只用合成标题/摘要。

## 当前怎么用

Docker Desktop的WSL集成当前不可用，`docker`命令失败、Docker socket不存在，原7876未监听。**本轮新增功能仅在独立本地预览 http://127.0.0.1:7877/research-tasks 可用**；使用独立会话、任务及收藏数据库，不能读取原Docker卷里的任务。本轮没有成功构建或更新Docker镜像。

1. 输入两味药材，确认来源、选择共同靶点，先完成本地关系核对。
2. 点击“读取来源文献ID（本地）”。每侧最多返回5条，保留该侧总数及截断标志；只列ID，不获取标题/摘要。
3. 在报告中查看PMID、来源ID、原JSON位置、原字段值、来源文件SHA-256及规范化目录行。下载Markdown包含相同内容。
4. 报告保持partial，文献证据表仍为空；“双方列出同一PMID”也不证明文章讨论双方药材、所选靶点或共同机制。原字段没有文献ID不等于没有研究。

读取前校验任务所有者、revision、来源和目录指纹；未完成来源/靶点选择、其他浏览器、旧版本或变化的目录不能写入报告。已保存线索再次读取幂等，刷新/下载使用冻结结果。操作消耗任务的一个工具额度；若原任务已经用完12次额度，需新建任务，页面不会提供不可执行按钮。

## 精确锚点修正

现有ETCM导入会对PMID列表去空白、去重、移除空项。派生目录中的序号可能因此偏离原JSON列表。新功能保留旧目录位置为 `catalog_pointer`，从同一哈希的基础库原字段重建 `source_anchors`；每个锚点含原JSON指针及未经去空白的原字段值，同一PMID重复出现的位置都保留。

派生行是 `{label, identifier}` 包装，原JSON指针指向的是字符串，不能把包装当成原JSON行。实现分别返回 `normalized_row`、`source_value` 和精确原位置，避免假溯源。若派生文献ID在冻结原字段中不存在，操作失败，不补造位置。本轮没有重建或改写近1GiB的旧关联目录，旧目录其他消费者的历史指针行为不因此自动改变。

## 文献对象核验契约

`tcm.task_literature.assess_candidate`是无网络、无模型的纯函数。当前未接收网页上的任意论文上传，也未将真实文章写入任务。未来冻结文献适配器接入前，可用合成记录验证以下规则：

- PMID必须与本次请求一致，且必须出现在指定已选来源的冻结线索中；不能只因另一个来源列出了该ID而通过。
- 复用 `literature_evidence.annotate_article` 读取撤稿、撤稿通知、更正通知及关注声明等元数据。撤稿/通知单列排除；缺少标志不等于文献质量通过。
- 复用 `research_objects.scope_signals` 定位原药材、成分、提取物、炮制和复方等提示词。提示词可能在否定句、背景或对照中出现，不能自动认定干预对象。
- 用户对象标注复用 `validate_reviews`，引用必须在冻结标题/摘要的指定字段中精确存在，并记录位置及哈希。匹配成功仍只是用户主张，不能升级为身份审核。
- 无摘要、对象不明、成分研究或仅有来源ID都不能补齐药材本体证据。输出始终明确对象身份、靶点关系、直接归因和质量评议未验证，不产生疗效结论。
- 内容哈希生成稳定证据ID；正文变化不会复用同一个内容ID。未来仍需任务级绑定、可信元数据获取和人工/独立语义核验，不能拿这组契约测试冒充模型研究能力。

## 验证与部署

最终80模块705项完整离线回归通过，跳过0、网络尝试0。新增10项离线测试覆盖来源PMID精确位置、重复与空白原值、5条截断、无ID、目录变化、幂等与恢复、预算、所有者/revision、合成撤稿/对象线索、无摘要、伪造引用及用户主张边界。实际7877页面验证使用已知白术/黄芪候选来源，核对双方2条靶点见证及2处文献ID原字段锚点；16项检查通过，测试任务已清理。不是独立用户评测或真实文章有效性评估。

原始测试、失败的Docker构建状态和本地预览结果在 `var/task_literature_v1/`，脱敏摘要见 [验收记录](../audits/task_literature_v1/summary.json)。没有Git提交或远程上传。


下一步接入按明确PMID获取并冻结文献元数据的适配器，区分来源ID存在、对象一致、靶点相关和引用语义支持。真实文献或药典/ETCM片段外发模型仍受原授权边界限制，本轮没有扩大授权。
