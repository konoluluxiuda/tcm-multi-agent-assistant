# 限定字段定位召回评测

## 问题与参考口径

过去通常每题只给一个目标片段，适合计算Hit@k，不能代表找全相关内容。本轮将分母明确为：**固定研究视图中，指定单一来源条目、指定字段集合的所有非空、非附录字段块**。直接遍历源视图生成参考，不使用被测检索输出挑选答案；重复字段和不同饮片范围全部保留。这里衡量的是字段位置覆盖，不是语义相关内容是否全部找全，也不是临床正确性。

六味药为金银花、连翘、桔梗、五味子、丹参、麦冬。24条题目由AI在检查字段可用性后设计：6条规范用途、6条用途改述、4条用量加贮藏、2条重复性状范围、6条价格/未知药/炮制品/缺字段/多对象边界。与现有eval目录的cases.question做了完全相同文本排查，未发现相同问题；这不能证明语义独立。题目来源、选择理由和用途写在[题集](../eval/scoped_recall_v1.json)。这是开发诊断，运行后进入回归；没有独立人工黄金集或新用户日志。

18条检索题共26个候选位置（题间有重用），每题分母1至3个。其中五味子性状的一处只有标题，仍保留在分母，并标记正文不完整；检索器将其放在unresolved_evidence，不作为已取得的证据命中。该题即使找到另外两处也只有2/3覆盖。丹参性状全部定位仍为ambiguous_field，不能据此自动选择炮制品或判任务完整完成。空/引用字段不从失败分母中删除。

边界题另计6题，不计算分母为0的Recall。仅当状态在事先允许集合内，且没有返回hits或unresolved_evidence时，才判边界处理正确。实体/字段识别从确定性方法实际query_interpretation核对；全库BM25没有这样的路由阶段，对应指标为null。
