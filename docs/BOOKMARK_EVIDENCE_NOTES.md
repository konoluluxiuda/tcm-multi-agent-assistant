# 收藏研究证据笔记

日期：2026-10-20。把已有收藏用于带出处整理资料，停止扩展收藏管理范围。源码预览7875已交付，Docker镜像未更新。

## 使用与范围

在“研究收藏”中找到已保存的项目，点击“导出证据笔记”，下载Markdown文件。需要携带个人笔记时勾选“包含已保存的个人笔记”；默认不包含。未点击“保存修改”的输入不会出现在文件中。它导出单项查询的来源材料，不生成多来源综述、药材身份核准、疗效比较或作用机制解释。

| 文件 | 作用 | 内容 |
|---|---|---|
| JSON备份 | 在另一浏览器恢复收藏副本 | 标题、笔记、查询和来源绑定；不自动导出来源正文 |
| Markdown证据笔记 | 带出处阅读和整理单项研究材料 | 来源查询结果；个人笔记仅在勾选后单独列出；不能作为JSON备份导入 |

药典收藏复用现有单药证据清单：保留OCR原文、含未审核修订的研究视图、字段/标题原页定位、PDF物理页码与SHA、范围、修订ID和缺失/重复字段提示。遵守原最多5个字段片段的预算，不把未人工核验资料改成批准结论。

ETCM收藏按原来源和原页码重新读取，最多20项，不遍历整份目录。导出当前目录总数与本页数量、计数单位、选定来源、原始行、JSON位置、文件SHA及抓取状态；候选路径保留药材端和靶点端两份见证。重复分组内的见证截断标记原样保留，目录覆盖不是召回率，关联不是已验证机制。导出20项不能称为已导出全部关联。

个人笔记明确单列为“用户记录，不作为资料证据”，不参与检索、不发送给模型。标题按字面转义，笔记及原始行使用能处理内嵌反引号的文本代码块，不当作HTML或指令执行。文件包含用户选定的来源文字及可能勾选的个人笔记，不附带Cookie、整份PDF或ETCM数据库。

## 工程边界

GET `/api/research/bookmarks/{id}/report?revision=...&include_note=false`，只读当前浏览器所有者的已存项目；客户端不能提交证据正文。导出前检查收藏revision与来源绑定，导出后再次核对来源和收藏revision。其他浏览器404，旧revision或失效绑定409，来源未启用/不可读503；失败时不返回附件，也不改用模型补答。JSON备份导入的药典查询也需通过实际药名与绑定一致性检查。

Markdown包含收藏修订号、来源版本和指纹、格式及导出代码版本；响应private/no-store、attachment及nosniff，不创建公开下载链接，不修改聊天记录或焦点，也不保存新研究结论。药典分支先复用收藏预览确认查询/药名，再由既有清单导出器重新查询并核对快照；有两次本地检索，不是一次模型调用。文件最大3 MiB，超限明确失败，不静默截断来源行。

这不是自动论文写作或人工证据质量审核。原始资料问题和未核验状态仍存在，JSON备份、长期语义记忆、账户及自动跨设备同步的范围均未扩张。
