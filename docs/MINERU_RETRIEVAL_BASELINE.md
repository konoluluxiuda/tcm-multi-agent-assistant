# 药典研究检索基线与实际失败记录

2026-10-17。已实现独立的本地研究检索：从修订视图建立SQLite FTS5索引，返回字段原文、修订原文、源PDF页码/坐标及审核状态；不调用模型、不生成回答，未接入正式聊天或生产知识库。

**本页记录v1失败基线。** 白头翁标题漏切、正文并入白术的问题已在后续v4修复，并恢复另外3个同类条目；当前研究索引为v2、616候选，见 [修复与迁移记录](MINERU_HEADING_RECOVERY.md)。以下原始指标及失败记录保留，候选数和命中率均不是全文验收结果。

## 数据与实现

- 来源：`var/mineru_revisions_v1/research_view.json`，保留11条AI研究修订及原值。
- 索引：`var/mineru_retrieval_v1/research.sqlite3`，612个候选、8,650个非空字段块，约42.6 MiB；本机构建约1.48秒。
- 返回：chunk_id、药名、字段、作用域、text/raw_text、原始块/字符范围、原PDF SHA和物理页、坐标、修订ID及未人审状态。
- 字段块最长3,558字符；本轮没有比较更细切分、向量检索或重排，不据此声称这些方案不需要。
- 查询连接使用SQLite只读模式，并核对索引文件SHA。原ETCM数据库、原始PDF与识别文件未改动。

两种方法在同一索引上比较：

1. `bm25`：中文单字/双字及拉丁词分词，整库词法检索，药名/字段/正文权重3/2/1。分数不是正确概率，没有额外拒答阈值。
2. `name_field`：从查询中匹配已知中文药名和预设字段意图，查询对应原文字段；遇到多药名、未支持字段、未观察到字段或重复字段，返回明确状态。限定单实体、预设字段，尚不是完整中文意图理解或实体消歧系统。

`name_field`的预设字段覆盖和实体约束与BM25不同，因此结果反映两条路径的实际行为，不能把差异全部归因于排名算法。

## 冻结的问题与参考

先保存 [28个问题](../eval/mineru_retrieval_questions_v1.json)，再实现检索：20个新编问题、4个范围/缺项问题、4个已知失败回归。问题为AI编写，不是收集到的真实用户问题；四个已知失败不并入新问题的指标。

[定位参考](../eval/mineru_retrieval_reference_v1.json) 采用来源辅助方式：先以现有语料定位，再查看原PDF标题及字段裁图，核实首处证据锚点。粗略区域不是像素金标准；标注不是盲标，也没有人工签核。不能据此计算全文字符准确率、临床正确率或线上任务完成率。

索引、问题、参考和排名参数在首次运行后未调优。初测文件保留；检查指标时补充“参考存在重复字段”的排除条件，避免把BM25未报告歧义当作没有歧义。当前报告为 `var/mineru_retrieval_eval_v1_checked/evaluation.json`；原初测位于 `var/mineru_retrieval_eval_v1/`。

## 实测结果

以下均为本批20个新问题；“无歧义首位命中”要求目标证据排第一、参考字段只有一处且路由未报告歧义，不等于答案已被批准。

| 指标 | 全库BM25 | 药名＋字段 |
|---|---:|---:|
| 前5条命中目标字段证据 | 18/20 | 20/20 |
| MRR@5 | 0.80 | 1.00 |
| 首位命中目标参考 | 14/20 | 20/20 |
| 无歧义首位命中 | 13/20 | 18/20 |
| 正确返回范围/缺项状态（单列4题） | 0/4 | 4/4 |
| 已知失败回归前5命中（单列4题） | 4/4 | 4/4 |
| 平均查询耗时 | 8.92 ms | 0.20 ms |
| P95查询耗时 | 13.59 ms | 0.26 ms |

耗时是同进程预热后每题3次测量，排除了命令启动和JSON输出；索引打开及文件SHA校验另约33.28 ms。这不是Docker、HTTP服务、并发或LLM端到端延迟。全部结果中的原文/引用数据与源研究视图一致，但这项结构检查不证明引用内容适合问题或原文识别完全准确。本轮无LLM、嵌入或外部API调用。

## 具体失败与下一修复

### P0：白术混入白头翁

高清PDF物理130页（章节109页）左栏底部有白头翁标题、拼音/拉丁名及来源句。原始JSON的 `part-101-200:322`、`:323` 有文字但缺少 `text_level`，当前v3标题识别要求该标记，因而漏切，把白头翁直到下一条目的内容并入白术。

这使白术出现两组功效/用量。`name_field`报告重复字段；BM25可能把白头翁内容排在白术问题首位。早先怀疑炮制品歧义，原图复核后已确认是跨药材串入，不能用“返回了正确候选之一”掩盖。

原图定位及SHA保存在 [失败清单](../audits/mineru_retrieval/failures.json)，本地裁图为 `var/mineru_retrieval_reference_v1/white-boundary-failure.png`。该候选禁止作为已验收知识入库。

下一步：支持没有标题级别但具有中文名、拼音/拉丁名、来源句与版面关系的边界；扫描同类漏切。修复可能改变顺序型候选ID，需要先设计稳定来源身份及修订重基，不能直接按旧编号套用11条修订。

### 词法相关不等于目标药材/字段正确

- “丹参有什么配伍禁忌”：BM25前5未命中丹参注意字段，首位返回另一药材的禁忌。
- “陈皮该怎样保存”：BM25前5未命中贮藏字段。
- 茯苓问题：首位可能命中茯苓皮或土茯苓。
- 不存在药名、市场价格、多药比较和未观察到的注意字段：BM25均返回了相似片段，没有表示范围限制。

### 尚未覆盖的范围

路由只是已知药名子串匹配，不能替代别名和实体消歧；预设字段词表有限，独立的“禁忌”等栏目仍需补充验证。部分字段会包含后续无标题注释，如陈皮贮藏后的植物变种说明。没有测试真实用户问法、复杂跨字段问题、模型生成、向量方案或并发性能。
