# 按集合大小匹配的随机对照（P2e）

2026-10-23，沿用P2d的128组疾病开发样本。**本次未观察到任何一组的最大共同靶点数超过其随机最大交集的第95百分位。** 当前共同靶点数排序没有在这个对照下展示出额外的区分依据，继续保留为来源集合检索。尚未验证疾病预测或疗效，也不能由此断定个别关联不存在。

## 实验约定

在计算前写入`protocol.json`，绑定[P2d基线](DISEASE_RANKING_EVALUATION.md)的协议SHA、来源指纹和逐条样本集合；不重新挑选疾病。使用1849条有靶点的药材来源，其靶点集合固定，背景为这些来源收录的962个不同标识。

对每条疾病：

1. 将疾病靶点分为背景内和背景外。仅用背景内数量确定随机抽样大小；背景外标识仍保留在原始Jaccard并集和单独计数中。
2. 从背景中均匀、不放回抽取同等数量靶点，重复256次。总种子`20261023`，每条来源的独立种子由总种子及来源ID的SHA-256派生；背景和来源顺序固定。
3. 每次对整个药材候选池重新计算交集，记录**最大共同靶点数**，避免只对已经选出的首位药材做比较。该最大值对照针对共同靶点数，不等于已评测随机Jaccard最大值。
4. 另外对原有两种排序的前10项报告规模期望、实测差值和模拟分布。这些是选出候选后的描述，未将其作为校正后的显著性检验。

若背景大小为`N`，疾病背景内靶点数为`D`、药材靶点数为`H`，均匀抽样下的交集期望为`D × H / N`。方差为`D × (H/N) × (1-H/N) × (N-D)/(N-1)`；空背景及单元素背景单独处理。代码通过小集合全部组合穷举核对公式。标准化差值仅作诊断，不按正态近似输出显著性或疗效概率。

## 实际结果

共32768次随机集合抽样、60588032次候选交集计算；本次单次批处理17.361秒。全部128组有背景内靶点。

| 最大交集诊断 | 结果 |
| --- | ---: |
| 各疾病实测最大交集的平均值 | 91.375 |
| 各疾病随机最大交集均值的平均值 | 93.899 |
| 实测最大值高于各自随机最大值第95百分位 | 0 / 128 |
| 实测最大值高于全部256次随机最大值 | 0 / 128 |

第95百分位采用排序后第`ceil(0.95 × 256)`项。“0/128”仅描述这个样本、背景和随机模型，不是对全部疾病的显著性结论。有限重复次数不能证明概率为零。

| 原Top10候选的诊断（各1280个位置） | Jaccard | 共同靶点数 |
| --- | ---: | ---: |
| 实测交集平均值 | 81.281 | 83.061 |
| 同规模随机期望平均值 | 80.103 | 84.197 |
| 实测减期望的中位数 | +0.551 | −1.199 |
| 实测/期望之比的中位数 | 1.006 | 0.985 |

Jaccard实测/期望之比的均值为1.342，但中位数只有1.006；少数期望很小的候选有很高比值，最大约32.07，因此不使用均值或单个高比值宣传效果，也不直接把比值替换为默认排序。

## 能说明与不能说明的事

本轮结果让“共同标识越多，候选越有针对性”的解释缺少支持。已有来源、双方原始记录核对及可复现集合检索仍有用途；预测有效性需要额外证据。

这个随机模型只控制集合大小。它固定药材集合及药材侧的结构，但不保留疾病侧各靶点出现频率、疾病间相关性或网络结构；使用本地药材背景也不代表完整生物学背景。全部疾病来源仍缺明确物种字段，源关联证据等级未核验。同一来源体系的开发样本不是独立标签。

没有新增排序公式、训练模型或更改聊天默认行为。当前也没有证据支持“换成逆频率加权就更准确”。若后续研究确实需要预测，再按明确任务补独立标签，并在未参与调优的样本上验证。
