# 本轮单药证据清单导出

2026-10-18：在主聊天、独立研究聊天与证据研究台增加“导出本轮证据 Markdown”按钮。它保存当前查询返回的字段，不是整味药材全部条目或综合文献报告。

## 使用

- 主聊天启用药典研究工具后，输入 `/research 甘草的功效`，在证据区点击导出；追问 `/research 它的用量` 后导出会使用已解析的“甘草的用量”。
- 独立研究聊天输入“甘草的功效”，或在证据研究台选择“药名＋字段定位”后查询，再点击导出。
- 浏览器保存 `tcm-evidence.md`。本地预览入口为主应用 `http://127.0.0.1:7871/`、研究聊天 `http://127.0.0.1:7869/chat` 和研究台 `http://127.0.0.1:7869/`；实际服务需运行新版代码。Docker 尚未更新。

名称未确认、多药名、药名歧义或未明确字段时不提供导出；BM25 探索结果不转换成单药报告。缺失字段、炮制品范围未解析、重复字段歧义与引用未展开可以导出诊断清单，但不成为完整答案。

## 文件内容和范围

文件包含查询和状态、索引及研究视图 SHA256、检索/保护/导出代码 SHA256、字段与条目 ID、范围、原始检查标记、修订 ID、OCR 原文及研究视图。引用保留来源文档标识、物理页码、章节页码、来源 SHA256、块 ID 和坐标；印刷页若仅为预期值会注明。

每次最多返回五个字段片段。匹配数超过上限会明确标注截断；本轮没有返回的请求字段单列，不用其他药材补齐。空字段、未展开引用及相邻引用提示独立列出；炮制品范围不明时仅列母条目标题定位，不复制母药字段。没有把检索状态当作人工质量批准。

Markdown 由服务端重新读取只读索引生成，不接收客户端证据正文，不调用模型或联网，也不写入会话历史。导出附带页面检索时的索引 SHA256；索引更换、PDF/索引文件变化时拒绝导出，要求重新检索或维护者校验重启。相同查询、来源与代码版本生成相同内容，不附带每次变化的时间戳。

文件含所查字段的来源文字，应按原资料的使用范围保存和分享；原 PDF、绝对路径、密钥、Cookie、会话数据库不随导出。源文本置于长度自适应的代码围栏内，元数据转义，避免源 Markdown 或 HTML 被当作报告结构执行。

## 接口

两个服务均支持只读 `GET /api/research/report?q=<明确药名和字段>&snapshot=<检索返回的index_sha256>`，不依赖会话焦点；聊天追问须先解析完整查询，再导出。服务端始终使用药名＋字段路由和上限五，不接受 `path`、自定片段或客户端历史。

成功返回 UTF-8 `text/markdown`、固定下载名和 `no-store`。无效/重复/未知参数或不适合导出的查询返回 400（主服务缺必填参数由 FastAPI 返回 422），快照改变返回 409，主服务禁用或来源不可用返回 503。原页图片仍由已有证据接口提供，不嵌入文件。

## 验证

- 新增 10 项导出/主接口测试，覆盖双版本文本、物理页与章节页、原始来源 ID、重复范围、缺失字段、截断、相邻引用、炮制品保护、版本改变、非法参数、禁用与会话不写入。
- 完整离线回归 319 项通过，无跳过和网络尝试；不调用真实模型。
- 主聊天浏览器 8 组、独立研究入口 10 组通过，包含真实 Markdown 下载、追问、来源预览与服务/浏览器重启恢复；研究台实际下载麝香原文和修订对照。
- 这些验证不代表全文准确率、人工签核、Docker 运行验收或镜像发布。
