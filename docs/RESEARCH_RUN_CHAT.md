聊天中可直接问“随便提供两个疾病及id”“请给我2个疾病和ID”“列出三个疾病名称及编号”。本地目录按稳定顺序列出指定数量（1–20条），不是随机抽样；表格直接显示名称和来源ID。编号是本项目来源记录ID，不是ICD或其他标准疾病编号。分页和回看保留数量。复合请求不会仅截取前半句执行。

## 类似问法与连续目录查询

2026-10-24追加：疾病目录意图统一放入 `tcm/disease_discovery_intent.py`，支持礼貌前缀、阿拉伯/中文数量、名称/ID表达与完整问句匹配。

- “请帮我列举两种疾病并附上ID”“随便给2个疾病”：返回两条。
- “给我几个疾病及编号”：默认五条；“给我十一种疾病和ID”：十一条。
- “数据库里有哪些疾病”“查看疾病列表”：默认20条目录。
- “再给两个疾病”“疾病下一页”“疾病上一页”：沿用当前会话的疾病目录、关键词、分页大小和版本。数量与上一页不一致时提示继续原分页或重新列出，避免换页尺寸造成重复/跳项。
- 数量0或超过20：明确提示范围。无疾病目录上下文时先提示浏览；数据库变化时要求重新查询。

含额外分析、文献或治疗要求的复合句不会被目录规则截断处理。这些规则仍不能覆盖任意表达，不代表已完成通用语义规划。模型意图输出也必须保持显式目录条数/页码；本轮用模拟模型验证，无新增真实模型调用。

验证：43项定向回归通过；浏览器完成1→2→1页查询和超限提示验证，无页面脚本错误。报告 `audits/disease_discovery_v2/summary.json`。7879预览已重启，Docker未更新。
