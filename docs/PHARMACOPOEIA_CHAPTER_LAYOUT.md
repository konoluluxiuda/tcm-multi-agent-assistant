# 药典按章节选择来源与解析规则

采用“相同章节类型复用配置，不同章节先检查”的处理方式。文件来源、页面栏数和条目语义分别登记，不能把一整份 PDF 一概判为单栏或双栏。

## 实际抽查

本轮直接渲染查看 11 个物理页，原 PDF 指纹与已有记录一致。这里的单/双栏表示**一张 PDF 页面内正文的文字栏数**，与阅读器单页/双页显示模式不同。抽查结果如下：

| 章节/页面类型 | 来源与物理页码 | 观察 | 处理决定 |
|---|---|---|---|
| 药材和饮片正文 | 434页文件：24、218；全本：51、247 | 两个版本的这些对应样页均为双栏 | 可复用药材双栏 OCR/条目规则，页面坐标分别计算 |
| 凡例 | 434页文件：12 | 单栏 | 应整栏阅读，不能使用左右半页 OCR 或药材标题切分 |
| 植物油脂和提取物 | 全本：467 | 双栏，有制法、油脂/提取物指标 | 可参考双栏阅读顺序，条目字段须另做验证，当前不放入药材提取器 |
| 成方制剂 | 全本：1030 | 双栏，存在处方、制法等结构 | 单独设计处方及制法范围，不能套药材来源/拼音/拉丁名起点规则 |
| 拉丁索引 | 全本：2057 | 双栏，索引行带页码 | 单独解析索引关系，不作为药材正文入库 |
| 封面、章节扉页 | 全本：1、49、465 | 标题页 | 仅帮助定位章节，不进入药材条目提取 |

因此，目前抽查证据不支持“这两份文件一份全是单栏、另一份全是双栏”。确实存在单栏页面，但变化也发生在同一文件内部。上述结论仅覆盖样页，不能外推为全书每页都已检查。观察由 AI 读图产生，未取得人工签核。

查看 [脱敏版式记录](../audits/pharmacopoeia_layout/layout_check.json)。页面图仅保存在忽略目录 `var/pharmacopoeia_layout_check/`。

## 相同章节如何复用

重叠的药材和饮片章节优先使用较清晰的 434 页版本；“全本”用于复核、确认缺页的补充，以及另一份没有收录的章节。已知 434 页版本在印刷页27至30之间缺页，对应印刷28、29可用全本物理76、77页补充。这里不是全书完整页码映射，不能用固定偏移推算其他位置。

复用的是 OCR 引擎、版面阅读顺序、字段和边界规则。不同扫描件的大小、边距、倾斜及置信分数仍须分别检查，不复制另一文件的像素坐标。相同印刷页不重复作为两个独立药材计数；来源分别保留，不能无条件拼接两份 OCR。当前尚未实现自动去重/冲突裁决及补页拼装。

扩大到一个新章节前，先检查章节开头、居中、结尾及异常版式。确认内容类型和栏数后，为该章节建立独立配置；仅布局相同可以复用 OCR 阅读顺序，但字段含义与切分规则还需验证。章节内部遇到单栏/双栏混排、表格、空白、附属标准或跨页标题，另列异常或拆分计划。

## 本轮代码约束

新增显式章节计划 [v2计划](../eval/pharmacopoeia_batch_pilot_v2.json)，沿用原九页范围，声明 `chapter_profile: herb_monographs_two_column_v1` 和页面 `layout: two_column`。**没有重新识别九页，也没有将这次抽查称为全章验收。**

批处理入口现在拒绝：

- 新计划没有声明章节配置；
- 成方制剂、索引等未适配的章节配置，即使也是双栏；
- 混入单栏页面或不同章节配置。

原 v1 九页计划仅以完整内容指纹允许历史重放；修改它扩大范围后，必须声明章节配置。v1 历史运行记录和缓存保持不变。新计划单独输出，避免覆盖历史：

```bash
/tmp/tcm-ocr-sample-20261016/bin/python -m scripts.batch_pharmacopoeia_pdf \
  --plan eval/pharmacopoeia_batch_pilot_v2.json \
  --out var/pharmacopoeia_batch_pilot_v2 \
  --reuse-ocr-dir var/pharmacopoeia_pdf_benchmark/rapidocr \
  --reuse-prepared var/pharmacopoeia_pdf_benchmark/pages \
  --max-new-pages 2
```

此命令仅为后续重新运行的方式，本轮未执行。缓存目前不跨输出目录共享，因此新目录只会复用计划中有固定旧结果指纹的五页，其余页会重新 OCR。

这些检查约束的是**计划声明**，尚不是自动识别版式的分类器。如果把实际单栏页错误声明成双栏，代码目前无法自动发现，仍需新增章节前的读图检查。单栏、提取物、制剂、索引当前仅完成版式抽查，没有宣称它们已具备专用提取器。

下一步继续原来的30–50页独立边界验证，限药材和饮片双栏正文；其他章节分别建检查样本和提取配置。
