# 仅药材和饮片章节的PDF导出

按用户要求，从现有两份扫描件中单独提取“药材和饮片”正文。本步骤只复制PDF页面，不进行OCR、不重采样图片，也不向解析平台上传。

## 章节范围

| 来源 | 物理PDF页码（从1开始） | 用途 |
|---|---|---|
| 434页文件 | 24–48 | 高清章节前段 |
| 2058页全本 | 76–77 | 补入已确认缺失的印刷28、29页 |
| 434页文件 | 49–434 | 高清章节后段 |
| 2058页全本 | 51–463 | 另存同章节的原扫描参考版 |

高清补页版共413页，范围以一枝黄花/丁公藤开头、麝香结尾。去掉封面、凡例、章节扉页及空白，不包含后续植物油脂/提取物、成方制剂或索引。“药材”沿用药典这一章节的范围，包含饮片及章内动物、矿物类条目，并非只筛植物来源药材。

高清源已确认物理48页为印刷27页，下一物理49页为印刷30页，因此在二者之间插入全本76、77页。其余页面沿用源文件顺序；没有宣称两份下载扫描件已通过官方真实性或全量印刷页号核验。

## 本地文件

输出在忽略目录 `var/pharmacopoeia_herbs_pdf/`：

- `药材和饮片_高清补页版.pdf`：以较清晰的434页扫描件为主，补入两页较低分辨率的原扫描。
- `药材和饮片_全本原扫描版.pdf`：全本中的章节原样提取，清晰度较低、体积较小，便于单文件对照。
- `上传分卷/`：高清补页版每卷最多100页；单卷不超过180,000,000字节。若超过，自动减小该卷页数，不降低扫描分辨率。
- `page_map.json` / `page_map.csv`：章节物理页 → 原始PDF、原始物理页、来源SHA，以及上传分卷名和卷内页号。
- `export_report.json`：文件SHA、页数、大小、校验结果及已知补页信息。

分卷文件名中的“第001–100页”等表示**导出章节内部的PDF页号**，不是原始PDF页号或书内印刷页号。页表中的`expected_printed_page`为预期连续标签；只有少数锚点有直接读图记录，不把预期值伪称逐页核验值。

上传分卷只是按页拆分，可能在条目中间截断。后续解析后须按`page_map`恢复章节页序，再处理跨卷接续，不能将每卷开头续文当作独立药材。补页版是一个新的派生文档，应使用其独立SHA和页码，并通过页表追溯到两份原文件。

## 复现与检查

固定导出计划见[页面范围](../eval/pharmacopoeia_herb_export_v1.json)。使用已有PyMuPDF环境：

```bash
/tmp/tcm-ocr-sample-20261016/bin/python -m scripts.export_pharmacopoeia_herbs_pdf \
  --out var/pharmacopoeia_herbs_pdf_recheck
```

输出目录必须不存在，不覆盖旧成果。运行前后检查两份源文件SHA；逐页比较内容流、嵌入图像及掩码内容、图像位置、页面尺寸/裁切范围和旋转。全部章节与分卷均以选定原始页为依据检查，不以“文件能打开”替代页面对应校验。该检查证明导出没有改变所选页面内容，不能证明原扫描没有其他错页或识别错误。

原PDF和导出PDF均只在本地保存，不随Git提交或Docker镜像发布。脱敏记录见[导出审计](../audits/pharmacopoeia_herb_export/)。
