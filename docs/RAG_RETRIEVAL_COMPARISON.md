## 证据的实际边界

这30题多数已指定药名和字段，共用解析器可将候选缩到一个或几个字段，因此高Hit/MRR**不能证明语义检索、LLM或自主Agent必要**。当前参考由作者AI核对原页/JSON，待人工签核；不是独立专家集。相关集合不完整，**不报告全库Recall**，原文位置/字面覆盖也不冒充生成陈述受支持。

另外验证了真正开放的贮藏搜索（614个字段候选）以及两药无指定字段搜索（35个字段候选），BM25/dense/混合均可返回带出处、范围正确的候选；这些是接口检查，没有完整相关集或人工排序标签，不能写成语义准确率。开放dense无校准接受阈值，始终是候选，不据余弦分数认定回答正确或覆盖全部。

同版本向量已经可用；249条嵌入截断、词典/字段规则的覆盖范围、用户真实语义问题不足仍是限制。命中后回读完整父字段，不代表嵌入理解了被截断的尾部。R3需要新证据组装预算；暂不靠新增框架或重排掩盖这些缺口。

## 运行与复现

精确/BM25无需安装ONNX，可直接运行（输出结构化候选，无生成）：

```bash
.venv/bin/python -m scripts.eval_rag_retrieval query \
  --method exact --question '白术的药典保存条件是什么？'

.venv/bin/python -m scripts.eval_rag_retrieval query \
  --method bm25 --question '查找与受潮和虫害有关的贮藏说明，保留出处'
```
