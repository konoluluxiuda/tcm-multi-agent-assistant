## D1资料工作台入口

2026-10-29：已新增[批量资料核对与表格交付](DATAOPS_D1_DELIVERY.md)。用本地预览启动后打开`/dataops`，可按目录筛选或输入“白术”“黄芪”各一行，选择药典字段并生成带来源的XLSX；刷新后可回看。当前固定本地流程不调用模型，唯一候选仍标待核验。文献搜索已退役，下文历史文献示例不再执行联网；已有批次与引用继续保留。

更新：2026-10-29。适用于当前源码的本地预览。启动方法见[项目README](../README.md#本地运行)，使用该命令后的地址是 **http://127.0.0.1:7896/**；管理员改过端口时，以启动输出为准。旧文档中的7876/7877/7878是历史实例，不能据此判断服务现在是否运行。

本地预览默认关闭外部模型、联网搜索和PubMed，不需要Tavily密钥。需由管理员准备本地索引和源资料；使用者无需上传PDF或填写密钥。另一台电脑不能通过自己的127.0.0.1访问此服务。

## 先试这几类问题

每行作为一条消息发送。示例用于上手，部分已参与开发测试，不是独立评测集。

| 需求 | 可复制的问题 | 预期结果 |
|---|---|---|
| 了解能力 | `你能做什么` | 当前启用的能力和资料范围 |
| 介绍资料 | `介绍两个数据库` | ETCM与药典各自内容和用途，不要求药名 |
| 数据数量 | `数据概览` | 当前索引计数；来源记录数不等于药材种数 |
| 药材属性 | `我需要查看白术的相关属性` | ETCM属性及来源 |
| 指定多项属性 | `查看白术的药用部位和科名` | 按ETCM分别展示字段与出处，缺字段时保留缺项 |
| 资料能力 | `药典的数据能查到哪些字段` | 介绍药典字段与用途，不要求药材名称 |
| 药典字段 | `黄芪有什么作用` | 功能与主治原文候选及出处 |
| 连续追问 | 接上一题发送`用量呢`、`出处呢` | 沿用已识别对象；新会话需先明确对象 |
| 成分记录 | `白术有哪些成分` | 来源收录的成分行，可分页核对 |
| 共同靶点 | `我在整理当归与川芎，想核对共同靶点，并保留双方原始记录的位置` | 共同UniProt及双方原始行；普通查询无需核对请求清单 |
| 靶点画像 | `白术的靶点画像` | 当前来源的去重靶点及缺失情况 |
| 相似来源 | `哪些药材与白术的靶点集合最相似？列前10个，并显示共同靶点和依据` | 集合相似度、共享标识及依据 |
| 疾病目录 | `浏览疾病目录`、`查找疾病 diabetes` | 来源名称、ID和后续查询入口；需启用疾病索引 |
| 多步骤查询 | `当归的靶点画像，川芎的靶点画像` | 同一计划执行两个画像，返回各自结果和出处 |
| 多工具查询 | `当归的靶点画像，查找与川芎靶点最相似的药材，前5个` | 画像与相似来源分别展示，不丢弃一项要求 |
| 药典对比 | `比较白术和黄芪的功效与用量` | 分药材、分字段原文对照及证据导出 |
| 跨来源研究 | `比较当归与川芎的药典功效和用量，核对全部共同靶点，保留双方原始记录的位置` | 同一任务返回属性对照、全部交集及双方记录 |
| 多种资料字段 | `查询药典当归的功效，查询川芎的ETCM药用部位` | 按资料分别返回字段原文与出处 |

有多个ETCM候选来源时，核对名称、部位和来源后选择；唯一候选可直接查询。中文候选与药典对象尚未全部核验。查询结果缺字段或没有记录时会保留缺项，不自动补造。不要把示例中的结果数量当作所有数据版本的固定答案。

## 如何阅读和保留结果

多步骤研究先返回“研究任务已排队”，随后更新进度和结果；关页不会取消。结果先显示摘要或表格。“查看”“来源与说明”等折叠区保留原始行、JSON位置、文件摘要或药典原页。需要引用时展开核对，不必逐项阅读内部执行信息。大结果显示预览；两药共同标识默认预览5项。打开“完整证据（按需查看）”分页读取，或下载完整JSON。每页最多20项，同时受6KB上限约束，实际项数可能更少。刷新保留原运行；证据丢失或来源改变会提示重新核对，不自动查询替换。见[证据保存与读取](RESEARCH_EVIDENCE_OFFLOAD.md)。

普通共同靶点查询默认展示首页。两药报告明确要求“全部共同靶点”时支持受控分页，当前上限10页、每页20项；预算不足保留已读结果并标记未完成，不把部分结果说成全量。该报告现已作为受控工具接入新多步骤聊天。全量任务先按最高14次读取检查剩余预算，实际按派发次数扣减；无法容纳时不开始该动作。见[报告工具统一](RESEARCH_REPORT_TOOLS.md)。

新多步骤聊天覆盖八个业务工具：原五个结构化分析，加药典字段、ETCM属性、两药证据报告。文献检索、任意下载任务、治疗或预测等要求仍未纳入统一计划；证据下载只是读取已完成的工具结果。规则未识别时，默认本地预览会说明限制；只有显式启用意图模型时，才可能发送当前问句进行一次提案，不发送资料或会话历史。

“本地研究”面板可生成单药/两药报告；`/research-tasks`保留较早的任务清单流程，用于明确计划和来源核对，不是普通聊天查询的必经步骤。

## 会话、收藏与项目记忆

- 同一浏览器、同一状态目录可恢复已完成消息和来源焦点；清理Cookie或换浏览器不会自动同步账号。
- 研究收藏需手动保存。笔记是个人记录，不是新的药学证据；清空聊天与删除收藏是不同操作。迁移前先导出收藏备份。
- 项目记忆保存明确填写的研究背景；语义候选检索需另外配置本地模型，不是默认自动记住全部历史。
- 新多步骤查询在后台执行，同一会话刷新可查看进度和结果。点击“取消任务”才结束任务；中断后可点击“恢复已保存步骤”。若上次调用是否执行不确定，会保留部分结果并停止，不自动重查；数据、代码版本变化也会拒绝恢复。见[后台执行与恢复](RESEARCH_PLAN_LIFECYCLE.md)。

## 遇到问题

| 现象 | 操作 |
|---|---|
| 页面打不开 | 核对启动输出和端口；本地预览7896与Compose默认7872是两种配置 |
| 提示未启用 | 联系管理员检查功能开关、索引和挂载；改问法不会自动开启功能 |
| 问法不识别 | 写全对象和字段，或使用下方明确指令；保存原句供排查 |
| 来源多于一个 | 选择本次查询要使用的来源，不直接默认同名资料属于同一对象 |
| 刷新后结果失效 | 核对资料版本、会话Cookie和状态目录，重新查询 |
| 已有研究任务运行 | 查看原任务进度或取消；重复提交不创建第二个活动任务，原任务焦点保留 |
| 中断后不能恢复 | 核对来源/代码版本和执行预算；已取消任务不能继续，未知派发不会自动重试 |
| 两窗口修改冲突 | 刷新后核对最新记录，不直接覆盖另一窗口的修改 |
| 系统报错 | 保留原始问句、请求编号、时间和操作步骤交给管理员 |

```text
/research 黄芪的功效
/herb BaiZhu
/relations 靶点药材 Q07973
/relations 靶点成分 Q07973
```

当前服务用于资料研究。来源靶点、相似度和疾病候选排序不能证明新靶点、作用机制或个体治疗效果。更完整的限制见[统一大纲](TCM_PROJECT_ROADMAP.md)；管理员演示与故障验证见[演示指南](PROJECT_DEMO.md)。
