# 新用户使用说明与模拟测试问题

2026-10-21源码预览更新：当前访问 **http://127.0.0.1:7877/**；研究任务页为 **http://127.0.0.1:7877/research-tasks**，已支持[真实ETCM问句和清单核对](LOCAL_TASK_REQUEST.md)。下方7876镜像说明保留其历史适用范围，Docker尚未更新。

适用版本：本地`tcm-research-chat:c4de8bc`，2026-10-20。用于中草药资料检索和来源核对。以下问题是上手示例，部分复用已有开发用例，不属于真实新用户独立评测，也不报告准确率。

## 1. 进入服务

当前入口：**http://127.0.0.1:7876/**。这是部署电脑的本机地址；其他电脑不能直接通过自己的127.0.0.1访问此服务，需要管理员提供访问方式。当前服务没有公开部署或账号登录系统。

管理员已准备资料时，使用者只需浏览器，不需要下载PDF、上传JSON或填写模型/Tavily密钥。当前药典与ETCM已就绪，ETCM版本为`local-2026-10-10`。资料更新后，数量和检索结果可能变化。

这个版本可以查询药典字段和原页、ETCM属性与关联、靶点成分及关联药材，比较两味药材的药典记载，保存研究收藏并下载证据。当前AI整理、自动模型规划、PubMed、联网搜索、图像及语音关闭，普通资料查询不调用外部模型。当前入口具有有界自然语言识别能力，不应把它当作能回答所有开放问题的通用聊天模型。

## 2. 第一次使用：五分钟流程

1. 输入`你能做什么`，再输入`数据概览`，了解已启用的工具与本地资料范围。
2. 输入`黄芪有什么作用`，查看药典字段候选，展开来源和原页；“未人工审核”表示需核对资料，不表示专家已批准答案。
3. 紧接着发送`用量呢`、`出处呢`，观察是否沿用刚才的药材。切换任务后，建议重新写全药名，避免把不同来源混用。
4. 输入`白术有哪些成分`。出现中文名称候选时，核对拼音、部位及来源ID，再选择本次使用的ETCM来源；不要直接把中文候选当作已验证的药典对象。
5. 使用卡片上的翻页按钮读取后续来源行。展开“原始行/出处”可查看原值、JSON位置、文件SHA和抓取状态。
6. 展开“研究收藏（持久保存）”，填写标题及个人笔记，点击“收藏当前查询”。以后通过“预览收藏”重新读取已绑定来源。
7. 输入`比较白术和黄芪的功效与用量`，查看并列表格，点击“导出对比证据 Markdown”。文件分药材、分字段保留原文及出处，不生成用药建议。

## 3. 可以复制的模拟问题

每条单独发送。连续追问必须接在前一步查询后；涉及中文ETCM候选的题目，需要点击选择来源才能继续。

| 场景 | 输入问题 | 应观察什么 |
|---|---|---|
| 功能介绍 | `你能做什么` | 工具范围与启用状态 |
| 资料概览 | `数据概览` | 当前ETCM有效来源记录数、药典候选条目数；两个数量不相加 |
| 原始分类 | `有哪些功效分类` | 原始分类值及记录数；不是人工统一后的分类体系 |
| 药典字段 | `黄芪有什么作用` | 功能与主治候选及出处；不是个体用药建议 |
| 连续追问 | 紧接上一题：`用量呢` | 沿用黄芪，查询用法与用量；缺项仍提示缺项 |
| 原页证据 | 紧接上一题：`出处呢` | 同一查询的证据定位和原页入口 |
| ETCM属性 | `在ETCM查询BaiZhu的药用部位` | 来源属性原值与JSON位置，和药典对象分开理解 |
| 成分来源 | `白术有哪些成分` | 先选来源，再查看成分行及分页；当前白术样本有307条来源行 |
| 共同靶点 | `白术和黄芪有哪些共同靶点` | 核对双方来源，按明确UniProt找交集；不是共同药效证明 |
| 成分候选路径 | `白术的成分关联哪些靶点` | 先选来源，查看三字段匹配的候选路径及双方证据；不是已验证机制 |
| 靶点成分 | `CYP24A1有哪些成分` | 当前解析到Q07973，查看靶点来源直接列出的成分行 |
| 靶点反查药材 | `CYP24A1关联哪些药材` | 当前Q07973返回19条药材来源记录；不作药效排序 |
| 靶点分页 | `P04278关联哪些药材` | 点击下一页后仍固定P04278，来源ID不重复；可进入某条药材来源 |
| 双药对比 | `比较白术和黄芪的功效与用量` | 两味药/两个字段分列，可下载Markdown原文证据 |
| 缺失字段 | `比较白术和黄芪的功效与注意` | 缺项保持未完成/partial，不拿另一味药或其他字段补齐 |
| 疾病富集 | `白术有哪些疾病富集记录` | 选来源，查看疾病原名、原始行和抓取状态；不是适应证或治疗推荐 |

结果数量对应当前快照及选定来源，不是永久固定的测试答案。“来源行数”“不同来源记录数”“不同UniProt数”是不同单位。例如，同一药材有多条靶点行，反查药材时只计一条来源记录；同名不同来源仍可能分开计数。

## 4. 模拟边界问题

以下例子用于确认系统能说明限制；没有完整答案不一定是故障。

| 输入/操作 | 合理表现 |
|---|---|
| `不存在样本草有哪些成分` | 没有匹配来源时要求核对名称，不编造成分 |
| `靶点CYP19A1有哪些成分` | 当前核对目录未覆盖时提示未覆盖，不声称现实中没有关联 |
| `比较白术和黄芪哪个更适合我` | 提示明确资料字段，不从对比结果推断个人选药 |
| `在PubMed检索 Astragalus membranaceus` | 当前部署提示文献工具未启用，不自动联网补答 |
| 在新会话直接问`出处呢` | 要求先明确药材/查询，没有凭空恢复别人的上下文 |
| 更改资料版本后预览旧收藏 | 指纹不一致时要求重新核对，保留旧笔记，不偷偷换成新来源 |

本节不是全局医疗安全或所有表达方式的验收声明。系统没有支持的问法可能提示查询范围；可改为完整药名和一个明确字段，必要时使用下方指令。

## 5. 无法识别问法时的明确指令

```text
/research 黄芪的功效
/herb BaiZhu
/relations 靶点药材 Q07973
/relations 靶点成分 Q07973
/relations 成分靶点 BaiZhu
/relations 疾病富集 BaiZhu
```

指令仍受同样的资料和来源校验约束。使用拼音只能定位ETCM来源，不建立它与药典中文条目的身份等价关系。

## 6. 聊天记忆、收藏与下载

- 聊天：同一浏览器访问同一服务可恢复近期消息和可识别的来源焦点；默认保留最近20条消息，闲置30天过期。服务重启不应丢失已完成回合，但不是跨账户长期语义记忆。
- 收藏：需手动保存，支持药典单药及已选来源关联查询；当前不支持把双药比较表、PubMed批次或AI回答直接收藏。清空聊天保留收藏；个人笔记不作为资料证据，也不发送给模型。
- 换浏览器：目前没有账号同步。清理Cookie或换浏览器前，先点“导出备份（含个人笔记）”，之后在新浏览器导入JSON副本；没有Cookie且没有备份不能恢复原收藏入口。
- Markdown：用于阅读、引用定位和人工核对，不能代替收藏JSON备份。收藏证据笔记默认不含个人笔记，需要时勾选后再导出；关联笔记只导出所收藏的一页。
- 共享电脑：同一浏览器配置文件持有同一访问凭据，并不会识别当前坐在电脑前的人。不同使用者应使用独立浏览器配置文件；无痕模式结束后可能丢失该入口，重要收藏先备份。

## 7. 常见问题

| 现象 | 建议操作 |
|---|---|
| 页面打不开 | 本机确认使用7876；其他电脑联系管理员提供入口，不直接使用自己的localhost |
| 显示未启用 | 当前功能开关关闭；不能靠换问法启用，需要管理员调整配置 |
| 中文药名要求选择 | 核对ETCM来源候选的拼音、部位及来源ID，然后明确选择 |
| 没有某字段或零条关系 | 核对来源与抓取状态；当前未记录不等于现实中不存在 |
| 收藏失效 | 来源或规则版本变化，重新查询并核对，旧笔记可保留 |
| 两窗口编辑冲突 | 刷新收藏列表后核对最新内容再修改；不会自动覆盖另一窗口 |
| 处理失败 | 保存页面请求编号、原始问法、发生时间与操作步骤，交给管理员排查；没有编号时说明是否断网 |

当前是本地资料研究服务，缺少正式账户与多用户生产准入；科研证据、实体身份及医学结论仍需人工核对。更完整的部署边界见[当前本地交付记录](releases/RESEARCH_LOCAL_C4DE8BC.md)。


### 合成计划的请求范围核对（2026-10-21）

在7877研究任务页选择计划范围，可勾选原请求中的第三药材或药用部位表，检查系统是否列出未覆盖项。普通确认不能略过这些要求；明确同意仅执行当前范围后仍会保留原请求未完成状态。操作仅验证合成工作流，不会执行第三药材查询或调用模型，详见[请求覆盖说明](REQUEST_COVERAGE.md)。


### 本地合成问句入口（2026-10-21）

在7877任务页“合成问句入口”输入“示例甲草和示例乙草有哪些共同靶点？还要药用部位并排表。”。先对照原句修订清单并声明核对完整，再确认计划、来源和靶点。草稿可能误读否定或漏项，未识别要求可逐行补充；不可执行项会保留，输入不发送给模型。原文及人工修订确认后可在刷新/服务重启后恢复，并随报告导出。详见[清单核对说明](REQUEST_COVERAGE.md#问句入口先核对请求清单再规划2026-10-21)。

### 真实ETCM问句入口（2026-10-21）

在7877任务页“用问句创建ETCM本地任务”输入“白术和黄芪有哪些共同靶点？请保留双方原始记录。”。核对对象和全部要求后，确认两味药的计划、双方来源及本页1至2个靶点，再下载报告。未知药名可手动补进清单，但无法解析来源时会停止；第三味药、文献等未执行项需明确同意暂不执行，并继续列为未完成。名称建议只做本地字面匹配，不自动理解否定或代词；输入和资料不外发。详见[使用、状态与限制](LOCAL_TASK_REQUEST.md)。
