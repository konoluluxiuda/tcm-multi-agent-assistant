## 本地运行

```bash
/tmp/tcm-ci-mail-env/bin/python -m scripts.run_local_research \
  --diseases var/disease_catalog_v1/build/diseases.sqlite3 \
  --disease 'Dermatosis Papulosa Nigra'
```

此命令使用确定性离线驱动，只读本地目录，不创建真实模型。先按原名/来源ID唯一解析，未找到或不唯一时返回`needs_input`和候选，不猜译名。输出含具体范围覆盖、步骤、证据和结束原因，原始结果可能较长；尚未接入聊天页面。

真实工具调用复用`tcm/analysis_tools.py`的`invoke`，先支持疾病名称搜索、疾病来源靶点资料。药材工具需要来源解析参数，仍待适配；本轮没有复制药材/疾病业务查询逻辑。

本地适配器通过子进程执行同步SQLite读取，子进程环境不继承模型密钥，拦截标准socket连接/发包与域名解析入口。取消时kill并wait回收子进程；每次查询前后及整个运行结束核对数据库/WAL状态。工具调用不修改原数据库，也不通过改变父进程环境在并发任务之间切换数据库。这里没有后台任务队列或持久checkpoint。
