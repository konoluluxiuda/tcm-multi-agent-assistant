# 模拟用户入口失败修复

2026-10-20。本轮针对另一AI实际操作中发现的入口失败做回归，不增加新工具或模型，也不把同一批问句称为新的独立验收。

## 已定位的原因与修改

- “我想看看黄芪的用量和注意事项，这里有吗？”被药名上下文守卫拒绝：“看看”未被识别为查询前缀。新增有限礼貌前缀，炮制前缀和未知长名的保护仍先执行，不截掉药名范围。
- 同题包含多个字段，原查询若只返回用量可能仍显示candidates。现在单独列出missing_fields，已有字段与未取得字段并列说明，标为partial；不补造注意内容。缺字段时仅保留唯一、无歧义来源的轻量焦点，供继续查询出处。
- “帮我找一下甘草，我主要想看药典怎么写的”没有匹配字段或名称入口。增加完整有界语法，保留完整药名/炮制词，只定位名称并要求选择字段，不直接返回全文。
- 询问资料覆盖范围却因同时提到药典和论文被要求二选一。覆盖范围问句现在优先回答实际功能与开关；真正请求跨来源查询仍走原澄清分支。
- 原模拟来源追问“这段是药典原话吗？我能看看它在书里哪一页吗？”按有限语法识别为来源追问，只重查当前会话的来源；不猜代词或确认OCR已等同原书。
