# 研究任务页面：合成资料流程验收

后续更新：已接入[真实ETCM本地关系任务](RESEARCH_TASK_ETCM.md)，当前页面同时提供两种模式。下文保留初版合成页面的验证范围；真实模式仍无模型/联网调用。

2026-10-21新增独立任务页面 `/research-tasks`。页面复用[有限工具任务引擎](BOUNDED_RESEARCH_TASK.md)，由规则驱动，全程不调用外部模型，不读取真实药典、ETCM或文献。CLI 已有的原生 tool calling 测试与此页面演示分开计数；不能用页面成功率代表模型或真实业务准确率。

## 使用步骤

1. 从聊天页“研究任务流程演示”进入，选择合成场景并创建任务。
2. 逐一确认示例甲草、示例乙草的来源；不同来源不会自动合并。
3. 在返回的共同靶点中选择1至2项，再继续核查。
4. 查看工具动作、观察记录、证据范围和缺口，下载 Markdown 报告。首次无结果的场景会进行一次补检；成分证据、对象不符、撤稿和工具不可用不能算作药材本体证据。
5. 刷新后，在“本浏览器的任务”中打开原任务继续。中断任务需明确确认重试，不重置已消耗的预算。

不提供真实药材问题输入框。两份来源记录指向共同靶点，不表示药理机制得到证明；合成报告“完成”只表示预设的软件核查步骤完成。

## 存储、隔离与并发

- 专用 SQLite 文件，由 `RESEARCH_TASK_DB` 指定；Compose 使用持久卷里的 `/app-memory/research_tasks.sqlite3`。不使用进程内字典保存任务。
- 独立签名 Cookie 名为聊天 Cookie 名加 `_tasks`，只保存其 SHA-256 摘要作为任务所有者。签名密钥使用现有会话数据库的持久密钥，重建容器时需同时保留该库与任务库。清空聊天不会删除任务；清除 Cookie、丢失会话库或换浏览器后无找回入口。
- 所有读取、选择、恢复、导出、删除接口都验证所有者。其他浏览器即使知道 ID，也只能收到404；列表不会列出CLI创建的无所有者任务。
- 每个浏览器最多20项，配额检查与创建处于同一 SQLite 写事务。用户可显式删除任务。目前没有账号、跨设备同步、任务备份或自动过期清理。
- 修改须提交整数 `revision`；SQLite 使用比较版本更新，旧页面返回409。单进程内再按任务串行协调修改，避免恢复请求将正在执行的步骤误判为中断。
- 当前面向本地单 worker；进程锁不支持多 worker 的执行租约。横向扩展前需补数据库租约、任务过期回收与并发恢复验收。预算预留不是 exactly-once 执行保证。
- GET 只读任务，不调用工具；创建、选择、显式恢复使用 POST。修改请求拒绝跨站 Origin/Fetch-Site，Cookie 为 HttpOnly/SameSite=Lax。匿名 Cookie 隔离不等同于生产账号鉴权。

## 开关与接口

默认 `ENABLE_RESEARCH_TASKS=0`，关闭时页面与API均返回404且不创建任务库。只在需要演示的部署显式设置为1。页面无原生模型开关，传入 `native`、任意问题、所有者或额外字段均不能启用外部调用。

| 方法 | 地址 | 作用 |
|---|---|---|
| GET / POST | `/api/research/tasks` | 当前浏览器列表 / 创建固定合成任务 |
| GET | `/api/research/tasks/{id}` | 只读状态、待选项、结构化工具记录 |
| POST | `/api/research/tasks/{id}/choose` | 提交版本和候选来源/靶点，继续至下一暂停点或结束 |
| POST | `/api/research/tasks/{id}/resume` | 按版本继续，重试中断需 `retry_interrupted=true` |
| GET | `/api/research/tasks/{id}/report` | 下载本任务证据报告 |
| DELETE | `/api/research/tasks/{id}?revision=N` | 按版本删除 |
