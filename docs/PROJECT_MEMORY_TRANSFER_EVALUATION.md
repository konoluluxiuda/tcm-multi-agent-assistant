## 两处上下文修复

1. 原来按“这次/本次/现在”多次切分，只取最后一段。“这次只看白术的贮藏，现在还要注意事项”会丢掉白术及贮藏，回退到旧项目对象。现在从第一个当前要求标记开始保留后续所有分句，并保留原始问句。
2. 原来“不要当归，只看白术”会把两个名称都当作当前对象。现在检测否定片段中的已知药材，返回明确冲突，要求用户在报告表单填写保留对象；尚未实现任意自然语言否定的自动逻辑解析。

初始应用场景10/12，失败A04/A05；修复后同题回放12/12。回放复用原始向量分数，未再次编码、未修改标签；这只说明已知上下文缺陷修复，不能称为检索或模型理解提升。
