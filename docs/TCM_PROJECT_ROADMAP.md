# TCM DataOps Agent：统一大纲与真实状态

更新：2026-10-30。**当前主线已调整为跨源资料核对、可追溯表格交付和持续修订，服务于大模型应用岗位求职。** 本文是唯一任务顺序与状态入口；[实施方案](DATAOPS_WORKBENCH_PLAN.md)定义需求、技术选择、模块和评测细节。D1批量核对与固定交付流程已完成验收；D2执行图、持久人工等待和增量v2已做本地工程验收；网页使用合成模型替身，真实模型效果仍未验收，见[D2交付](DATAOPS_D2_DELIVERY.md)。

## 目标与边界

面向资料整理人员，用自然语言提出筛选、补充字段、差异核对及修改要求；Agent根据工具观察选择行动，最终交付可预览、可下载、可修改的结果。真实场景使用ETCM药材记录与药典；通用性来自数据库＋文档协作，而非宣称已经支持其他行业。

主演示：核对20条药材，补充药典功能主治/注意，区分缺失、差异与歧义并输出带来源表格；随后只重查有问题记录、增加指定字段、生成v2及差异。50条本地来源的v1/v2规模验收已通过。数据清洗仅给建议，原始记录只读。

不再把方剂推荐、靶点预测、机制研究、全库实体对齐或通路富集作为近期前置任务。文献搜索网络入口和菜单已退役，历史读取继续兼容；多Agent、沙箱、Skills平台、新外部MCP和复杂长期记忆不阻塞首版。

## 当前代码实际能做什么

聊天中明确的表格整理与字段续改先走`/chat → DataOpsService → 有界目标编译 → 原队列/持久图 → SyntheticDriver → 工具/产物验证 → 聊天结果卡`。普通查询仍走`/chat → 规则或单次问句提案 → 对象/要求校验 → 来源解析 → RunScope → 队列/worker → DeclaredActionsDriver＋A journal → 本地工具 → 校验与结果展示`。没有默认开启真实观察回传模型的自主任务循环。另有新工作台`/dataops → 有界问句编译或手动Goal → 原队列/持久图 → SyntheticDriver → 本地工具 → 表格验证/版本交付`；支持范围内直接执行，未识别要求阻止入队，不是通用LLM理解。

## 已作出的技术选择

- 保留Python、FastAPI、LangGraph 1.x、DeepSeek兼容接口、SQLite和Qdrant；继续A单Agent路线，不重开B/C框架竞赛。
- 新业务用StateGraph表达目标、动态行动、观察、验证与必要人工输入；模型负责策略，程序负责筛选统计、机械分页、字段比较和文件生成。
- 新DataOps图采用原生持久Checkpointer，首版单机SQLite；复用现有队列/SSE。旧journal只恢复旧A路径，不让同一新运行被两套机制恢复。原生checkpoint不自动解决外部请求未知派发，仍需保留派发状态和幂等约束。
- D1锁定openpyxl；D2安装并锁定`langgraph-checkpoint-sqlite==3.1.2`、aiosqlite 0.22.1、sqlite-vec 0.1.9，兼容checkpoint 4.3.1，核心框架未升级。
- 结构化查询使用受限参数契约与参数化SQL；现有检索和身份比较按需适配。MCP默认不是批量工具的必经传输。
- 从零组装教程和LCA课程只借鉴机制，不复制云沙箱、内存持久化、完整SDK依赖或销售助手。固定源码与取舍见[方案第2节](DATAOPS_WORKBENCH_PLAN.md#2-两个参考项目的核验与取舍)和[架构决策](ARCHITECTURE_DECISION_REVIEW.md)。

## 评测口径

30题协议已冻结并运行：开发18、作者前瞻保留12，覆盖查询统计、批量核对、连续修改、必要澄清/恢复及范围外。**测的是结构化Goal业务契约，三策略使用替身；不是30题自由问法/真实模型准确率。** 修复评测器后各策略开发18/18；保留题首测各12/12，执行后已转为回归题。 来源参考从固定JSON和文档建立，不从被测输出反推；审核状态如实记录。无人独立出题时不称独立真实用户集。

固定流程也保留正常分页和异常处理；三策略共享工具、数据、预算、验证器。反事实观察只证明行为对观察敏感，不单独证明LLM有收益。完整交付、正确部分结果、等待、失败、not_run分别报告；数据缺失是否允许任务完成由事前契约规定。

主要指标：任务达成、记录集合/字段准确、引用支持、增量修改正确、工具与底层读取次数、token与活跃耗时。原保留集目标10/12在此次离线契约检查达到12/12；这不替代真实模型业务评测。严重错对象/虚构来源/越权仍为0容忍。全部细节见[方案第8节](DATAOPS_WORKBENCH_PLAN.md#8-评测协议小规模但能解释结果)。

## 外发与发布约束

现有默认预览仍关闭模型和联网。既有授权只覆盖当前问句的单次意图识别，历史有限测试授权不能覆盖新循环的真实资料、云沙箱或追踪上传。先完成本地工具与合成替身验收；真实模型实验准备具体题目、资料范围和总预算后单独取得授权，not_run不写成通过。

D1已实现独立工作区、固定本地核对和XLSX交付，预览可直接使用；文献网络传输与菜单已退役，历史只读回看保留。已安装表格依赖并将Compose的文献开关固定为0，未构建镜像或提交Git。新模式默认关闭，显式`--dataops-synthetic`仅开启本地模型替身，状态/产物使用独立目录；回滚关闭入口即可，旧流程与历史checkpoint保留。
