# 药典研究查询：字段改述与有限字形支持

2026-10-18，本地实现 M2-03 的一部分。适用于药典独立研究索引及主聊天 `/research`，不建立 ETCM 中文名称映射，不增加模型或外部服务。

## 可以使用的输入

主聊天示例：

```text
/research 黃芪的服用剂量
/research 它每次多少克
/research 黨參的药效
/research 何首烏的储藏条件
```

独立研究聊天和研究台使用同样问题，去掉 `/research` 前缀。研究聊天也可先输入“黃芪”选择条目，再追问“它每次多少克”。结果是来源字段候选，不是按个人情况计算剂量。

新增字段表达：

| 输入表达 | 定位字段 |
|---|---|
| 多少克、每次几克、剂量 | 用法与用量 |
| 药效 | 功能与主治 |
| 储藏 | 贮藏 |
| 使用警示、使用警告 | 注意 |
| 取自哪一部分、取自哪个部分 | origin（来源） |

这些是有限的词组规则，不是开放式自然语言理解。字段未提供时仍返回缺失；只含引用时仍提示未展开。原有功效、保存、归经等表达保留。

药名在原有 NFKC、大小写和空格处理上，仅增加四组字形对应：**黃/黄、黨/党、參/参、烏/乌**。名称必须落到实际索引条目；命中多个来源药名时要求消歧，不合并实体。已有炮制品优先保留最长完整药名，未收录炮制品不退回母药。未知复合药名也不能只凭子串通过。

**未支持拼音、医学别名、任意繁简转换或错字纠正。** `Gancao`、`Huangqi`、`Dangshen` 当前仍返回名称未解析。尤其冻结题中 `Dangshen → 党参` 只是原先待核验的检索假设，不能据此写入别名表或排除其他候选；未来需要来源支持、冲突处理及确认流程。

## 可追溯行为

检索响应新增 `query_interpretation`，记录规则版本、输入字形/索引名称和触发的字段词。页面与 Markdown 导出显示映射依据，保留原始问题和来源正文；没有改写 OCR 或修订层。BM25 的分词、词表及排名未调整，它仍是探索入口，不能据本轮药名路由改善宣称已完成混合检索。

规则保存在 `tcm/mineru_retrieval.py`，完成轮次记忆原本绑定该文件 SHA；规则变化后旧焦点会失效，需重新明确药名。新焦点保存索引名称，后续追问、出处回查及导出继续使用原有来源验证。

没有新增依赖，也没有重建索引。`normalized()`、`terms()` 和索引配方 `PARAMETERS` 保持不变；只有查询匹配、字段理解及其展示发生变化。

剩余三条药名变体均为拼音，保留失败。炙甘草未展开引用仍不计完整字段命中；四个有独立条目的炮制品证据为 3/4，不自动补全该缺口。

本轮规则依据已知失败编写，以上只是**已知案例回归，不是新的独立验收或医疗准确率**。不修改原题、参考、基线报告或评分器。另复验旧 20 题保持 20/20、四条范围问题及四条已知修复回归通过，返回内容与来源视图一致。
