## 改动

- `tcm/dataops/conversation_scope.py::field_followup` 支持“先给我”“再补上”“请再补充”等字段补充前缀，仍要求整句剩余内容完全是已知字段。新药名、否定、未知字段和额外操作不会通过该路径继承对象。
- `prepare` 不把纯字段补充中的“再补上药典”当作药名；最近用户轮次已经保存的空对象范围作为明确边界，不再从其原句重新猜药名。只有没有保存范围的旧消息才保留原有兼容解析，不向前翻找陈旧对象。
- `tcm/dataops/chat.py::clarification_message` 将含 `object_mentions`、`inherited`、字段命名空间等内部信息的澄清转为普通提示。正常的具体澄清（如基原与引用出处的区别）保留；原始问题说明仍保存在提案与诊断中，不增加润色模型调用。

这是限定字段追问的修复，不是任意多轮语义理解。已失败会话的空对象轮次不会被自动改写或跳过；继续那段旧会话时应重新明确药名。
