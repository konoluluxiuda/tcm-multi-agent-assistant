# 会话记忆与并发修复验收

2026-10-09。7862 修复容器挂载当前工作区代码，基础镜像为 8n1eld/medical-assistant:0.1.0。不是重新构建的发布镜像。

## 改动

- API 的 session_id 传入文本、上传及验证流程；省略 ID 的程序调用彼此独立。
- 同一会话的轮次串行执行，输出过滤和联网回答生成收到该会话历史。
- 允许正常的文献来源和页码查询；活跃 checkpoint 真正裁剪为最近 20 条消息。
- 单进程复用 RAG 实例、串行访问本地 Qdrant；关闭时释放客户端，初始化失败也释放目录锁。
- 将本地来源链接转换为 /data/...；读取时兼容旧索引 localhost URL。
- 修复重排失败时的返回格式；评测使用显式 session_id。

## 限制

记忆为进程内短期记忆：活跃上下文默认最近 20 条消息，重启清空。没有持久化、账户身份、跨设备同步或会话过期机制。MemorySaver 仍保留历史 checkpoint 版本；活跃上下文裁剪不等于总内存占用有界。

本地 Qdrant 排队方案限单进程，不能让多个 worker 共享同一目录。冷启动和联网仍慢，本次两个并发请求约 89/109 秒。

来源 URL 修复不代表页码级证据追溯通过。分数校准、医学准确性、长期记忆、中草药专项能力不在本轮验收范围。
