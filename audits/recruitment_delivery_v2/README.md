## 一条命令与回滚

输出目录须为新的，服务应已启动：

```bash
.venv/bin/python -m scripts.rehearse_recruitment_demo --dataops \
  --url http://127.0.0.1:7912 --out var/recruitment_demo_run1
```

7912可提供默认不勾选的一次模型理解，但本命令不会选用。native模式被拒绝，失败保留报告、不自动重试POST；文件或来源状态不符会失败，而不是删掉校验装成功。

当前容器复用 `var/rag_r4_v1/container-final-state`，旧容器 `tcm-research-r4-before-recruitment-v1` 停止保留供回退。回退不删除状态、不重写旧文件；已完成文件可读，不让旧实现恢复新版在途checkpoint。
