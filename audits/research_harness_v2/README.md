宿主在打开来源前重复检查前置条件，静态计划或绕过模型适配器的动作也受约束。重复同一检索与已读证据被拒绝，真实来源歧义仍可等待人工选择；可用的检索、回读、澄清及交付供模型选择，不注入代替模型的完成动作。拒绝或无进展分别记录，原决策/工具/来源预算及连续两次无进展停止仍保留。

新模块已纳入checkpoint实现版本及未来真实评测的源码冻结。新代码不静默恢复旧源码版本的checkpoint；原已完成工作区及下载继续可读。
