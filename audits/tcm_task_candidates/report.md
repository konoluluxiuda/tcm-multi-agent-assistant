`sparse_evidence` 用 `evidence_focus` 区分 `sparse=5` 与 `pmid=5`。执行方式为 `api=55`、`manual_ui=3`、`planned_chat=2`。55 条 API 题中含 3 条未支持中文名映射请求：API 返回明确降级的契约可检查，但所请求的中文实体解析能力仍标为 `unsupported`。其余 2 条未支持题是尚未接入的同会话来源追问、跨会话指代与隔离流程。

15 条详情题覆盖不同字段意图，包括多名称原文、科名、产地、部位、药性、味、归经、分类、功效、英文名定位、PMID、跨库标签、来源ID、两名称栏一致性与文件绑定。比较题逐格保留对象与字段，筛选题覆盖二至三条件、子串边界、分页偏移、同名不同来源保留。边界题另含未知拼音、空白条件、不支持筛选字段、非法分页参数、缺失字段，以及 HuaShi 歧义候选到来源ID的两步显式选择。

## 来源绑定与独立预期

源目录为只读的本地 `ETCM2.0/etcm_herbs` 快照，数据版本 `local-2026-10-10`，记录数 **2,076**。逐文件读取字节并计算 SHA-256；将按相对路径排序的 `[relative_path, file_sha256]` 对列表，以 `ensure_ascii=False`、紧凑分隔符序列化为 UTF-8 JSON，再计算总指纹：

`9921499429128fa21b4b8dc2c5100f359970d8fa796a1dcee32ca8259fe02d80`

原始 JSON 的基础段被独立遍历来建立字段预期、名称匹配集合和筛选结果；没有调用被测 repository、query API 或付费模型服务产生答案。详情和比较中采用名称查询的题目，对全快照的拼音、拉丁、英文名同时进行独立归一化匹配，确认其查询只对应预期来源；不以文件名假定别名唯一。显示预期按现有契约去除名称栏HTML标签、去首尾空白、列表去重；搜索键另做空白折叠和casefold，不把内部NBSP等搜索规则当成原始值修改。

10 个筛选条件组合分别独立遍历全部基础记录，得到命中数 **3、17、20、32、5、3、26、16、19、2**。候选保存完整匹配来源ID集合，以及对应分页的来源ID和路径。650 个 `source_evidence` 锚点涉及 176 个源文件，逐项保留相对路径、文件哈希、JSON Pointer 和原始值；重复出现的锚点按题保留。这些是选定字段与段落证据，不是全库原始数据副本。未提供字段的负证据引用整个 `base_information/value` 数组；返回字段自身的 `source` 仍应为 null，不能伪造缺失键路径。

本轮设计自检检查了数量、配额、split、规范实体/条件锚点隔离、全部名称查询唯一性，以及650个源锚点与独立读取的基础段索引一致性。主代理负责另行运行 CLI 校验器并保存报告。格式、哈希和原始值一致只能证明部分工程一致性，不能替代完整答案审核、科学有效性或实际任务执行。

## 分组与泄漏边界

`group_id` 和每个 `leakage_keys` 都不跨 dev/test。显式命名的药材实体采用归一化拼音实体锚点；详情、比较、边界、稀疏与聊天规划题的主要实体在两组间隔离。重复使用同一实体的题留在同一 split。`HuaShi .json` 和 `HuaShi_.json` 对应的歧义查询、来源ID选择共用同一 group，均置于 test。

筛选以字段和值经归一化后的完整条件组合为锚点；连续 UI 题继承每一步条件组合锚点。因此同一组合若在单步与连续题重复，保留在同一 split。共享的属性词、筛选结果中的偶遇实体以及来源证据可能跨 split 重叠；完整结果ID也会暴露这些实体。本划分**不是严格全实体隔离、统计独立或不可见数据的保留测试**。报告这些限制后才能解释未来结果，不应仅凭 dev20/test40 声称泛化能力。候选仍待人工审核和正式冻结，调参前应再次审计分组与访问边界。

## 人工审核与后续执行

人工需审核每条任务是否符合真实查阅需求、字段和条件语义是否合理、完整结果有无遗漏、成功判据能否执行、稀疏证据表达有无越界。PMID缺失只说明本库未列出；PMID存在只说明有关联ID，不能证明论文内容或临床疗效。传统功效、跨库标签和文献编号均不能自动充当现代科学结论。

在人工签核前保留草案状态。执行时固定服务提交与数据版本，按 `execution_instructions` 保存逐题实际输出、来源、状态、耗时、失败与审核结论；3 条 UI 连续任务需真实逐步操作，2 条聊天规划任务当前应登记未支持，不能用独立查询API代替会话执行。运行完成后才按既定分母报告结果；本轮未进行任务评测，也未证明所有源数据内容科学正确。
