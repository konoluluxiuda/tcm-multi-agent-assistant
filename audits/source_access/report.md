实际 HTTP：75 份登记文件（4 PDF + 71 picture PNG）响应内容 SHA-256 均匹配；1 条旧 PDF 引用正确重定向；11 类私有/无效路径返回 404，包括真实 Qdrant 数据文件、内部 docstore、已有前后台上传文件、共享输出、未知 ID 和编码穿越。报告只记录分类，不复制这些私有文件内容。[HTTP 原始结果](http_checks_2026-10-12.json)。

新增测试验证：未登记文件、目录穿越、双重编码、符号链接、内容篡改、无清单均拒绝；结果 token 需匹配 Cookie，会过期并受容量限制。双重编码最初造成校验异常，已修复为拒绝响应，回归通过。

上传 API 使用模型替身：A/B 只能下载各自不可变快照；后续生成不会覆盖旧快照；并发生成通过单进程锁保持来源正确；无 Cookie 拒绝；普通聊天不发布旧共享图片；分析异常也清理输入且不发布结果。测试文件全部为临时合成内容，未使用真实患者资料或付费 API。

## 边界

共享文献白名单不是账户鉴权：这些已登记资料可供本机服务使用者查阅。匿名图片结果使用 Cookie 和随机 token，账户登录及真实用户所有权仍待 M3；持有同一 Cookie 和 token 可取得同一会话结果。token 默认 10 分钟，进程重启失效。

全量原医疗镜像未重建；现有主容器通过源码挂载运行本轮修改。原上传文件没有被批量删除。语音供应商、真实 CV 推理和 RAG 付费调用没有在本轮复测，相关响应使用替身。

本轮不证明文献分发许可、资料的科学正确性、多人服务容量或跨进程图像后端一致性。登记图像的来源关联由管理员审核，清单冻结其字节，不证明与文献的派生关系。

用法：[SOURCE_ACCESS.md](../../docs/SOURCE_ACCESS.md)。M0-05 的既有数据暴露与同会话结果边界已完成，下一项建议 M0-06 将无付费回归接入 CI。
