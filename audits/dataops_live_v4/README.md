## 与V3的比较及结论

V3为F/P各3/3、A为1/3；V4为F/P各3/3、A为2/3。A这次完成增量任务，仍有多候选失败。两轮A均29次请求，V4上下文更大，token由45401增加到55332。单次已知题表现变化不能证明反馈改进有可重复因果收益，也不能证明A优于固定流程。

目前证据支持：宿主能阻止不合法读取、保留未知并诚实停止；真实A可完成部分观察循环和增量交付。证据**不支持**默认把常规整理交给A。P的工具计划仍有冻结阶段约束，本组也未显示P相对F的业务收益。

技术取舍：常规整理保留固定F；HTTP继续固定/合成模式，不因本轮2/3自动开启真实A。停止继续增加预算或重复三题刷兼容分。下一项转向**G：单次LLM目标提案与本地有界语法的对照**，共用固定执行器，先冻结问句/参考和预算，再实现类型化提案及澄清路径。衡量是否减少改问、遗漏与误执行；语义正确性由参考评分，不把schema通过当理解正确。观察异常组的新工具扩展暂缓，待目标理解实验和独立样本决定是否值得继续。
