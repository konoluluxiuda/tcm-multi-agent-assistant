## 约束与兼容性

- 原E02只查两个`herb_target_profile`的模型计划仍拒绝，成分要求不能消失。单个普通靶点问句兼容原画像工具，不因此放宽多对象/多类型覆盖。
- 原E03擅加药典字段的`pair_evidence_report`仍拒绝。原E07药典字段`missing`过滤也仍拒绝，没有静默改写旧坏参数。
- `filter_complete`新建提案用`target_count=null`；宿主编译后保存实际来源数量作为容量上限，沿用1–5交付预算，不表示必须凑满。必须检查全部候选并返回全部合格项；0项也是有效筛选。超范围或不支持附加要求时停止/澄清。
- 旧`audit_named`保留命名记录，`select_complete`仍挑N条，旧Goal默认值不变。续改保留父行；新增字段缺失时partial，不删除旧行或标成齐全。
- 只读子进程、源版本检查、读取计费、观察校验、私有大证据存储继续适用；新工具不推断成分→靶点因果关系。
- 本地语法有边界；Schema及词法覆盖不等于完整语义验证，新附加要求仍需评测。
