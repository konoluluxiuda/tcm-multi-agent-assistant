- 模型返回在业务校验前记录。有效响应保留解析后的工具参数，失败记录拒绝码、字段位置、对象差异及项目代码位置/hash；未知JSON仅保留hash/长度，未知异常不导出异常正文或栈局部变量。

- 开启Langfuse时，同一trace ID贯穿理解及后台执行，元数据带`diagnostic_request_id`；本地CLI不调用模型即可查已有记录。接口与用法见[诊断说明](../../docs/REQUEST_DIAGNOSTICS.md)。
